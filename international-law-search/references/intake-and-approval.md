# Intake and Approval Compatibility Router

This file is retained for compatibility with version-1 links.

- Read [`modes-and-rounds.md`](modes-and-rounds.md) for readiness questions, mode selection, scope approval, round budgets, checkpoints, upgrades, and closure.
- Read [`access-and-privacy.md`](access-and-privacy.md) before any authorized local intake inspection, institutional access, subscription use, or external retrieval.
- Deep-audit projects may also require [`../templates/search-plan.md`](../templates/search-plan.md) and coordinated workspace approval. Quick and standard modes use the lighter scope card and checkpoint templates unless the user requests audit artifacts.

Do not treat this router as an independent workflow. If older instructions conflict with `modes-and-rounds.md`, follow `modes-and-rounds.md`.
